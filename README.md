# 🚀 AI-Driven Surveillance and Threat Detection

An AI-powered surveillance system that detects weapons and threats in real-time using computer vision and a web dashboard.

---

## 🔥 Features

- 📹 Live Camera Streaming
- 🧠 YOLO-Based Object Detection
- 🚨 Real-Time Weapon Detection Alerts
- 🌐 Flask Web Dashboard
- 📊 Multi-Camera Support

---

## 🛠️ Tech Stack

- Python
- Flask
- OpenCV
- YOLO (Ultralytics)

---

## 🚀 How to Run

```bash
git clone https://github.com/Srishti-Jha123/AI-Driven-Surveillance-and-Threat-Detection-main-1-.git

cd AI-Driven-Surveillance-and-Threat-Detection-main

python -m venv ai_project

ai_project\Scripts\activate

pip install -r requirements.txt

cd src

python app.py
```
